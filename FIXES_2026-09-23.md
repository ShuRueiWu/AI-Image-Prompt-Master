# V9.4 language and preview fixes

Updated `Prompts Builder V9.4.html` in place.

- English UI now uses English built-in preset names, group names and all 50 quick-layout labels. Added English names for 13 presets without an English label. Search includes English names and descriptions; custom preset names remain user-owned.
- Replaced the automatic negative Simplified Chinese instruction with an independent Image Text Language selector: Traditional Chinese (default), Simplified Chinese, English, or unspecified. The generated prompt uses a positive language instruction. Text-free pediatric profiles suppress it temporarily. Existing user-entered text is not automatically translated.
- Moved the preview heading into normal document flow and corrected canvas aspect-ratio sizing. Section text wraps and can scroll; rounded rectangles avoid clipping text at circular corners. Applying a preset now retains its section directions.

Validation: actual Chromium interactions checked all quick layouts, English preset labels, search/no-result/reset, all four language outputs, square and portrait canvas proportions, heading separation, desktop/mobile views, light mode, and pediatric language suppression/restoration. No model API calls were made.

Original HTML backup: `/tmp/prompt-builder-v94-before-20260923.html` (temporary, not a permanent archive).

Follow-up: the language instruction is now directly editable beneath the language selector, with a reset-to-default button. Each language retains its own edits during the current session; blank instructions are omitted. Unspecified language and text-free profiles disable the editor and suppress the instruction. Edits are not persisted across page reloads.

Multilingual follow-up: added Japanese and Custom / Multilingual options. Custom starts blank and accepts arbitrary mixed-language instructions, including a different language for each text role, without appending a single-language constraint.

Contrast follow-up: parameter heading and language labels now use dark amber text in light mode; language badges use solid amber backgrounds, and the version badge uses a solid blue background with contrasting text. Matching FAQ heading styling was updated too. Chromium computed-color checks (including ancestor background compositing) measured light-mode contrast of 7.23:1 for the parameter heading, 8.15:1 for language badges, and 8.49:1 for the version badge. Corresponding dark-mode ratios were 11.79:1, 12.03:1, and 10.34:1. This is a targeted contrast check, not a full-page accessibility certification.
